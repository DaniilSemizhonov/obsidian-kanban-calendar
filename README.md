# Канбан-календарь

Плагин для Obsidian: календарь для задач с [Kanban](https://github.com/mgmeyers/obsidian-kanban)-досок. Плюс всё, что умеет [Calendar](https://github.com/liamcain/obsidian-calendar-plugin): мини-календарь в боковой панели и ежедневные заметки.

## Что показывает

- **Дата карточки** — `@{2026-10-11}` на доске.
- **Даты из свойств связанной заметки** — если карточка ссылается на заметку (`[[Пост]]`), а в `metadata-keys` доски перечислены её свойства-даты (`deadline_tz`, `publish_date`, …), каждая дата становится отдельным событием со своим цветом и подписью из доски («ТЗ», «Текст», «📅»).
- Если дата карточки совпадает с одной из дат заметки, это одно событие, а не два.
- Этап (колонка доски) — на каждом событии. Выполненные карточки и колонка, отмеченная как завершённая, — приглушены.

## Виды

- **Канбан-календарь** (вкладка, иконка на ленте) — месяц, задачи прямо в клетках. Клик по задаче открывает заметку (Ctrl/Cmd — в новой вкладке), наведение с Ctrl/Cmd — предпросмотр.
- **Мини-календарь** (правая панель) — точки по дням, список задач выбранного дня.
- Неделя начинается с понедельника, всё на русском.

## Перенос мышью

Перетащите задачу на другой день:
- дата карточки меняется на доске (`@{…}`);
- дата из свойства меняется в заметке;
- если событие объединяет обе даты — меняются обе, чтобы не разъехались.

Если доску успели изменить, перенос отменяется без записи. На телефоне перетаскивание не работает — это ограничение браузерного drag-and-drop на сенсорных экранах.

## Ежедневные заметки

Клик по числу — открыть заметку дня или создать её (с подтверждением). Формат, папка и шаблон берутся из встроенного плагина «Ежедневные заметки» (или Periodic Notes). Дни, у которых есть заметка, отмечены.

## Настройки

- какие доски учитывать (по умолчанию — все);
- показывать ли выполненные;
- показывать ли дату карточки отдельно, если она не совпала ни с одним свойством;
- подписи и цвета типов событий.

## Установка

Через [BRAT](https://github.com/TfTHacker/obsidian42-brat): «Add Beta plugin» → `DaniilSemizhonov/obsidian-kanban-calendar`, затем включите плагин в разделе «Сторонние плагины».

## Разработка

```bash
npm install
npm run check   # типы
npm test        # разбор досок и событий
npm run build
```
